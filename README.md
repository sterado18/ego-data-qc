# ego-data-qc

頭に付けたカメラで家事を撮影し、ロボット学習（模倣学習）に使える品質かを自動で判定する小さな検証。

> 作成中（2026-11）。結果の数字は撮影後に埋める。

## 結果

- 手順を【変えたこと】に変えた第2ラウンド：【Y】%

## 判定基準（scripts/score.py）

| 項目 | 基準 |
| --- | --- |
| 手の写り率 | 70%以上のコマで手が検出される |
| 両手の写り率 | 50%以上（タオルを畳むタスクのみ） |
| ブレ | ブレたコマが20%以下 |
| 照明 | 暗すぎ・明るすぎのコマが10%以下 |
| 長さ | 5秒以上、タスクごとの上限の2倍以内 |

## 使い方

```bash
bash setup.sh                       # 環境づくり（Ubuntu / macOS）
.venv/bin/python scripts/score.py   # data/raw の動画を採点 → reports/scores.csv
BUCKET=... bash verify_upload.sh    # 合格分を S3 に送り、件数・容量・チェックサムで照合
```

動画は公開していない（`data/raw/` は .gitignore 済み）。別の場所の動画を使うときは `EGO_RAW_DIR=/path/to/videos` を指定する。
